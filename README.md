## ⭐ Projeto em destaque

### [loft3d](https://github.com/felipehenriquee/loft3d) · [▶ testar online](https://felipehenriquee.github.io/loft3d/)

Configurador de cozinha planejada em 3D que roda direto no navegador. Feito em 2021, antes do ChatGPT e dos assistentes de IA para código.

- 🧩 Monte armários, balcões e paneleiros numa grade 3D, com regras de encaixe (chão, parede e tamanho de cada módulo)
- 📱 Veja a montagem em Realidade Aumentada no celular, em tamanho real
- 🔗 Monte no computador e leve para o celular por QR Code

`JavaScript` `Three.js` `WebGL` `GLTF` `model-viewer` `Vite`
